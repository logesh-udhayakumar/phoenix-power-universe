# Phoenix Power Universe — logo files

Generated by `scripts/generate-brand-assets.mjs` from the mark in
`src/components/public/phoenix-logo.tsx` and the proportions of the site header.
**Don't hand-edit these files** — change the component or the script and
regenerate, so the exports and the website never disagree about the logo.

## What's here

| File | Use it for |
|---|---|
| `phoenix-logo-square` | Avatars, app icons, favicons, social profile pictures — anywhere the frame is square. Gold bird on the brand near-black, rounded corners. |
| `phoenix-logo-horizontal` | The full lockup on a **light** background: letterheads, invoices, light website headers, slide decks on white. |
| `phoenix-logo-horizontal-dark` | The same lockup on a **dark** background — the wordmark is off-white instead of near-black. |
| `phoenix-mark` | The bird alone, no background, no text. For when the name is already written next to it, or for a watermark. |

Each comes as:

- **`.svg`** — vector, the one to use wherever it is accepted (web, print, Office,
  Canva, Figma). Scales to any size with no loss. The wordmark is outlined, so it
  renders correctly on machines that do not have Inter installed.
- **`.png`** — two pixel sizes per asset, **transparent** background. For anything
  that cannot take an SVG (WhatsApp, some marketplaces, older email tools).
  Square and mark: 512 px and 1024 px. Horizontal: 1200 px and 2400 px wide.
  Use the larger one for print or any retina screen.
- **`.jpg`** — the same two sizes, with a **solid background baked in**. For the
  places that reject PNG and SVG outright: some print portals, listing sites,
  marketplace seller profiles, older office templates. JPEG cannot hold
  transparency, so each one is flattened onto the ground it is designed for:

  | File | Background |
  |---|---|
  | `phoenix-logo-square-*.jpg` | brand near-black `#0b0c0e`, full bleed |
  | `phoenix-logo-horizontal-*.jpg` | white `#ffffff` |
  | `phoenix-logo-horizontal-dark-*.jpg` | brand near-black `#0b0c0e` |
  | `phoenix-mark-*.jpg` | white `#ffffff` |

  White rather than the brand's off-white, because these are the files that go
  into letterheads and documents, where `#fbfaf8` would show as a faintly grey
  box on the page.

  The JPEGs already include the clear space below, so the pixel size in the name
  is the **logo's** width and the file itself is a little larger — e.g.
  `phoenix-logo-horizontal-1200.jpg` is 1262 × 185. The square is the exception:
  its ink field is already its clear space, so it stays exactly 512 or 1024.

  **Prefer PNG or SVG whenever the tool accepts them.** A JPEG cannot sit on any
  background but its own, and re-saving one degrades it.

## Rules

**Clear space.** Keep empty space around the logo of about a quarter of its own
height on every side. Nothing — no text, no border, no photo edge — inside it.
The JPEGs have this built in; the SVGs and PNGs are cropped tight, so you add it.

**Minimum size.** The horizontal lockup is about 9.7 : 1, so it gets short fast:
below roughly 160 px wide the bird stops being readable. Under that, use the
square or the mark on its own.

**Backgrounds.** On a photo, use the square — the horizontal lockups are
transparent and need a plain ground to stay legible. Never put a light-background
JPEG on a dark surface (or the reverse): its own rectangle will show.

**Don't** recolour it, stretch it, rotate it, add a shadow or an outline, put the
gold on a mid-tone background, or rebuild the lockup by placing the mark beside
typed-out text. Use the file.

## Colours

| Token | Hex | Where |
|---|---|---|
| Gold | `#c8921c` | The bird |
| Gold light | `#e8bb4e` | The two crest plumes |
| Ink 950 | `#0b0c0e` | Square background, and the wordmark on light |

Typeface: **Inter Bold**, uppercase, `0.14em` letter-spacing — already outlined
in the files, listed here for anyone setting matching type.

## Regenerating

```bash
npm i --no-save opentype.js wawoff2 @fontsource/inter
node scripts/generate-brand-assets.mjs
```
